# Examples  
  
## MSX  

### Change Graph Kit  
A MSX program written with Basic Dignified and converted to classic MSX Basic.  
Change Graph Kit is an utility to find and modify uncompressed game graphics straight from a disk.  
  
**Dignified version**  
  [`CGK173.dmx`](https://github.com/farique1/basic-dignified/blob/main/examples/msx/CGK173.dmx)  
An MSX Basic program written the Dignified way.  
  
**Classic version**  
  [`CGK173.amx`](https://github.com/farique1/basic-dignified/blob/main/examples/msx/CGK173.amx)  
The classic ASCII code converted from the Dignified version.  
  
  **Binary version**  
  [`CGK173.bmx`](https://github.com/farique1/basic-dignified/blob/main/examples/msx/CGK173.bmx)  
The classic binary code converted with the tokenizer.  

  
**List file**  
[`CGK173.lmx`](https://github.com/farique1/basic-dignified/blob/main/examples/msx/CGK173.lmx)  
The list file generated by the tokenizer.  
  
> `CGKConf.cfg` and `CGKTools.com` are support files for Change Graph Kit.  
> `PETILSTG.BIN` is an example file to test Change Graph Kit and came from the game **[PetitLuster in G](http://blog.livedoor.jp/cobinee/archives/1866846.html)** from [Dwarf Play](http://blog.livedoor.jp/cobinee/).

## Addition: ZX Spectrum preview

The original MSX/CoCo examples above are preserved.

- [hello.DSP](zxspectrum/hello.DSP): first Dignified example, using explicit
  LET, a long numeric scalar name and IF/GO TO with a label.
- [colours.DSP](zxspectrum/colours.DSP): colours, FOR/NEXT, sound, GO SUB/RETURN.
- [data.DSP](zxspectrum/data.DSP): strings, arrays, DATA/READ and native functions.
- [functions.DSP](zxspectrum/functions.DSP): implicit LET, compounds, PRINT AT,
  Dignified FUNC/RET. Its expected SCORE is 10, followed by answer 20.
- [native.DSP](zxspectrum/native.DSP): 1.6.0 binary literals, chained
  statements, OUT and LIST/RUN with a label. Expected: BIN 7, CHAIN OK,
  A:B, then PRESS A KEY TO LIST. The border becomes blue. Press a key to
  list the final PRINT/STOP lines; PRESS A KEY TO RUN introduces a second
  pause. Another key runs the finish label, clearing variables/display and
  printing DONE.
- [hello.ASP](zxspectrum/hello.ASP): numbered listing generated with `-rh -ca`.
- [hello.tap](zxspectrum/hello.tap): tokenized BASIC in a standard TAP container.

```powershell
python -B badig.py examples\zxspectrum\hello.DSP -id zxspectrum --tk_tokenize -rh -ca
```

Expected output: SPECTRUM 1, SPECTRUM 2, SPECTRUM 3, then DONE.
Load manually in EightyOne configured for Spectrum 48K and enter RUN.
Each example has generated ASP/TAP/TZX companions; use `--tk_format both`
to regenerate both tape containers. On 2026-11-04 the user confirmed all
16 manual Spectrum 48K cases passed: four examples in TAP/TZX, with and
without BASIC autorun. This is user-reported manual validation, separate
from the automated conversion/format tests.
The new native example also has ASP/TAP/TZX companions, but its manual
emulator validation is still pending; it is not part of those 16 passes.
See the [Spectrum manual](../documentation/ZX_SPECTRUM.md).
