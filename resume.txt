Module layout
-------------
- zx81/badig_zx81.py: ZX-81 language description and parser hooks.
- badig.py: optional classic-lexer hook used by ZX-81 to scan quoted strings without changing MSX/CoCo behavior.
- zx81/tokenizer_zx81.py: pure-Python conversion from numbered .AZX text to ZX-81 .p program files.
- zx81/tokenizer_interface.py and zx81/tools_zx81.py: tokenizer settings and integration with the common build flow.
- zx81/emulator_interface.py: launches EightyOne.exe with the generated .p file.

- zx81/tokenizer_interface.ini: tokenization defaults.

Conversion flow and usage
-------------------------
Dignified .DZX -> numbered classic .AZX -> tokenized .p.

From the repository root:
- PowerShell: .\zx81\convert-zx81.ps1 zx81\samples\zx81-intro
- Bash/Linux: bash zx81/convert-zx81.sh zx81/samples/zx81-intro

Both helpers accept the source base name without extension, do not launch the emulator, and leave .AZX and .p next to the source. They have been tested with paths containing spaces. To run EightyOne through Badig, use --em_run; its interface passes the .p path to C:\zeddy\EightyOne.exe.

Implemented and tested
----------------------
- ZX-81 commands, functions, operators and numbered .AZX generation.
- .p header/system variables, line records, numeric encoding, tokens and graphics/inverse-video escapes.
- Long Dignified variable allocation Z, Y, ... A; string suffix $ is retained, and DECLARE-selected names are honored.
- Built-in [?](row,column) expands to PRINT AT row,column;. Defaults are 0,0; row-only sets column 0.
- Doubled quotes (`""`) and backslash-quote (`\"`) inside `.DZX` strings both encode to ZX-81 quote token 192. Doubled quotes are the preferred spelling. Numbered `.AZX` input supports both spellings too. Editor grammars and the VSIX have been updated for doubled quotes.
- Windows and Bash conversion helpers, VS Code tasks/extension, Sublime package, default INI values and documentation.
- Existing Dignified/MSX and CoCo ordinary-string conversion smoke-tested after the optional quote hook was added to badig.py.
- Both PowerShell and Bash helpers were tested on a valid sample, including paths with spaces.
